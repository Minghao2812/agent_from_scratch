# GUI agent 规则

1. 每一步只根据「页面背景信息 + 两张截图（上一帧、当前帧）」判断当前状态。两张截图
   看起来完全一样是正常的（虚拟时间推进的预算刚好落在游戏 tick 边界上）。
2. 背景信息里已经给出各元素的颜色、形状、控制方式——**严格依据背景信息识别截图中
   的元素，不要仅凭视觉猜测**（小模型在像素级颜色辨认上不稳定，容易认反）。
3. 当前测试系统只支持键盘操作，不支持鼠标点击/拖拽。只能输出方向键、其它按键名、
   `wait` 或 `stop`，严禁输出按钮文字或 click(...)。
4. 游戏是否结束只能靠这一步的视觉判断：看到明显的「游戏结束 / Game Over」画面
   （通常是半透明遮罩 + 文字）就输出 `stop`。
5. 严格按 JSON 格式输出，不要输出除 JSON 之外的任何文字。
