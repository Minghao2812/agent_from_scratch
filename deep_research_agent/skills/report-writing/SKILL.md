# 整合笔记，写一份带引用的专题报告

## 步骤

1. `read_file` 读 `plan.md`（checklist）、`notes/` 下每个子任务笔记、`sources.jsonl`（来源索引）——
   具体目录（每次运行独立、带时间戳）以系统提示里给出的路径为准，不要用某次运行里见过的路径。
2. 报告按 checklist 的子问题组织章节，每章先给结论，再给支撑证据。
3. 每一个关键判断后面标 `[id]`，id 对应 `sources.jsonl` 里的记录；同一句话涉及多个来源就写 `[3][7]`。
4. 结尾附"参考文献"列表：按 id 升序列出 `[id] 标题 —— url`。
5. `workspace/研报数据/` 里的内部数据（如果 checklist 涉及）也要在报告里体现，并明确标注"来自内部研报素材"以区分外部检索。

## 自查清单（写完report前过一遍）

- 覆盖度：checklist 里每个子问题是否都有对应章节？没查到的要写"未找到公开信息"，不能跳过不提。
- 引用密度：每个结论性段落至少一个 `[id]`；没有编号支撑的判断要标"（推测）"。
- 冲突处理：多个来源数字不一致时，两个都列出并说明分歧，不擅自选一个。
- 缺口坦白：workspace/研报数据/sources.md 里已知的数据缺口，报告里不能编数字填上。
